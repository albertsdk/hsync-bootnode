# Support

## How to get help

- **[Documentation](docs/README.md)** — requirements, install (`.deb` / source) and quick start.
- **[Usage reference](docs/usage.md)** — `run` options, environment variables, group keys, private nodes and OS services.
- **[GitHub Issues](https://github.com/albertsdk/hsync-bootnode/issues)** — bug reports and feature requests. Please search existing issues before opening a new one.
- **[GitHub Discussions](https://github.com/albertsdk/hsync/discussions)** — community questions, ideas and general discussion.
- **[Security Policy](https://github.com/albertsdk/hsync/blob/main/SECURITY.md)** — how to report security vulnerabilities privately.

## 💚 Solo project

HSYNC is a passion project maintained in spare time by volunteers. Feature requests, bug reports, and pull requests are reviewed as soon as possible, but response times may vary. Thank you for your patience and support!
